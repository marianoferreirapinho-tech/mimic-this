# Mimic This! v0.4 — Multiplayer foundation

Real Socket.IO multiplayer prototype using the approved Mimic This! UI.

## Included
- Create/join game codes
- Separate player sessions and private roles
- Fair actor rotation and random cards
- Server-enforced actor restrictions
- One active teammate vote per player
- Live reactions, guesses, reveal and score

## Run
`npm install`
`npm start`
